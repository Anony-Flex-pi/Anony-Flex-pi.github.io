# Flex-π — anonymous project page

Anonymised project page for *Flex-π: A Multi-Stream World-Action Model with
Compute Flexibility*, prepared for double-blind review.

```
index.html              the whole page (single file)
assets/css/style.css    design tokens + components
assets/js/main.js       charts, the mask configurator, video/lightbox, theme
assets/figures/*.png    figures from the paper
assets/videos/*.mp4     task clips (+ .jpg poster frames)
```

Static HTML/CSS/JS, no build step. To preview:

```sh
python3 -m http.server 8000    # then open http://localhost:8000
```
